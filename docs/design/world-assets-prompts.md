# Openfront world asset prompts

Generated with the built-in ImageGen pipeline using `openfront-primary-screen.png` as a style reference.

## Empty valley

Production 16:9 isometric city-builder terrain: a large empty dry-grass clearing, perimeter forest, river, rocks and subtle paths. Northern medieval earth-and-heather direction, warm late-autumn dusk, northwest light. No buildings, people, armies, interface, labels or text.

## Building atlas

Production 4×3 isometric sprite atlas on removable `#00ff00`: road, house, farm, lumber camp; quarry, granary, market, smithy; barracks, watchtower, wall, town hall. Equal cells, one complete centered sprite per cell, consistent camera/light/materials, no labels or UI. Chroma key was removed locally with soft matte and despill.

## Unit atlas

Production 2×1 isometric combat atlas on removable `#00ff00`: heather-purple town militia spearman and dusty-red tribal raider. Equal scale and facing, no labels or UI. Chroma key was removed locally with soft matte and despill.
