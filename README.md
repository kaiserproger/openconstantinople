# Openfront

Играбельный браузерный вертикальный срез градостроя с элементами grand strategy: детерминированная долина, свободное строительство, экономика поселения, голод, бунты, перевороты и динамические внешние угрозы с видимым боем на карте.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:5173`. Для стресс-сцены с 300 бойцами используйте `http://localhost:5173/?stress=1` и нажмите «Атаковать».

## Проверка

```bash
npm test
npm run typecheck
npm run build
npm run test:e2e
```

Управление: выберите здание в нижней панели и укажите место на карте. Верхняя панель меняет скорость, создаёт новую долину и сохраняет или загружает поселение. Кнопка «Атаковать» разворачивает бой с текущей внешней угрозой.

## Границы первого прототипа

Городская сцена использует цельный сгенерированный production-концепт как детализированную основу, а интерактивные постройки, ресурсы и бой накладываются поверх. Симуляция отделена от Vue и готова к переносу в Worker/Pixi-рендерер; в этом вертикальном срезе она работает в основном потоке, а сохранения находятся в `localStorage`.
