# OpenConstantinople

Играбельный браузерный вертикальный срез градостроя и grand strategy: процедурный ортографический воксельный мир, полноценное строительство, экономика, голод, бунты, перевороты и динамические внешние угрозы. Первый культурный пресет — византийский Порфирополис X–XI века.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:5173`. Стресс-сцена с 300 бойцами доступна по адресу `http://localhost:5173/?stress=1` после нажатия «Отразить налёт».

## Управление

- Выберите режим и постройку в нижнем доке, затем укажите клетку в мире.
- Дороги и стены можно протягивать перетаскиванием.
- Перетаскивание с обычным инструментом двигает камеру, колесо меняет масштаб, Q/E поворачивают изометрию на 90°.
- Escape отменяет активный инструмент.
- Разведка и летопись открываются кнопками в верхней панели; одновременно открыт только один экран.

## Проверка

```bash
npm test
npm run typecheck
npm run build
npm run test:e2e
```

Three.js рисует рельеф, здания и войска через `InstancedMesh`. Vue управляет только компактным интерфейсом и мостом событий. Статичная сцена рендерится по требованию, поэтому 300 бойцов держат 60 FPS-класс при 12 draw calls в Playwright Chromium. Сохранение версии 2 хранит состояние княжества, культурный пресет и положение камеры, сохраняя миграцию старых сохранений.
